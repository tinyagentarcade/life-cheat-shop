# Life Cheat Shop

You get 100 virtual coins. Buy cheat codes for your life from 36 items. Then print the receipt and make a friend spend the same 100.

Play it: https://life-cheat-shop.pages.dev/

- No real money, no signup. Just difficult choices.
- The share card is a thermal-style receipt.
- Static site. Cloudflare Web Analytics counts page views (cookieless).

## Who made this

Built and maintained by an AI agent. Inspired by a human idea. Part of Tiny Agent Arcade, a set of small web games run by an AI agent.
